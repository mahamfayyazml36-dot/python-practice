# 🧾 Invoice Generator Project

## 📌 About Project

Invoice Generator is a beginner-level Python mini project created by **Maham Fayyaz**.

This program generates a simple shopping invoice by taking customer details, product information, quantity, price, and discount from the user.

## 🐍 Language Used

Python

## 📚 Concepts Used

- Input Method
- Variables
- Type Casting (int, float)
- Dictionary
- Arithmetic Operators
- Calculations
- Escape Sequences (\n, \t)
- sep and end
- f-string Formatting
- .format() Method

## ⚙️ Features

The program can:

- Take customer name
- Add multiple products
- Calculate product-wise total
- Calculate total shopping bill
- Apply discount percentage
- Calculate final bill after discount
- Generate a formatted invoice

## 🛒 Invoice Calculation

The program calculates:

- Product Total = Price × Quantity
- Discount Amount = Total Bill × Discount Percentage / 100
- Final Bill = Total Bill - Discount Amount

## ▶️ How to Run

Run the file:

python invoice_generator.py

## 🎯 Purpose

This project was created to practice Python basics and understand how different programming concepts combine to build a real-world application.
