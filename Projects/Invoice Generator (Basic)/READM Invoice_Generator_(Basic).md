# 🧾 Invoice Generator (Basic) Project

## 📌 About Project

Invoice Generator (Basic) is a beginner-level Python mini project created by **Maham Fayyaz**.

This program takes customer details, item information, price, and quantity from the user and generates a simple shopping invoice.

## 🐍 Language Used

Python

## 📚 Concepts Used

- Input Method
- Variables
- Type Casting (int)
- Arithmetic Operators
- Multiplication Calculation
- f-string Formatting
- print() Method

## ⚙️ Features

The program can:

- Take customer name
- Take item name
- Take item price
- Take item quantity
- Calculate total bill
- Generate a simple invoice

## 🧮 Calculation

Total Bill = Price × Quantity

## ▶️ How to Run

Run the file:

python invoice_generator_basic.py

## 🎯 Purpose

This project was created to practice Python basics and understand how user input and calculations can be used to create a simple real-world application.
