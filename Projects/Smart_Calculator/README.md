# 🧮 Smart Calculator Project

## 📌 About Project

Smart Calculator is a beginner-level Python project created by **Maham Fayyaz**.

This program takes two numbers from the user and performs different mathematical operations according to the selected operation.

## 🐍 Language Used

Python

## 📚 Concepts Used

- Input Method
- Variables
- Type Casting
- Arithmetic Operators
- If-Elif-Else Conditions
- Nested If Condition
- Error Handling
- f-String Formatting

## ⚙️ Features

The calculator can perform:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Floor Division (//)
- Power (**)

## 🚫 Error Handling

The program handles division by zero and invalid operations by displaying proper messages.

Run the file:

```python
