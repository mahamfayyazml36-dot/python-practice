# 🎓 Student Report Card System

## 📌 About Project
This is my first Python mini project.
I created a Student Report Card System using Python.

This project takes student information and marks as input, then calculates total marks, average, percentage, and grade.

## 🚀 Features
- Takes student information
- Takes subject marks
- Calculates total marks
- Calculates average
- Calculates percentage
- Generates grades using if-else conditions

## 🐍 Python Concepts Used
- Input Method
- Variables
- Data Types
- Type Casting
- Arithmetic Operators
- If-Else Conditions
- f-Strings
