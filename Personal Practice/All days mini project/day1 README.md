# Mini Project 1 - Student Introduction

This is my first Python mini project.

## Concepts Practiced
- Variables
- print()
- input()

## What It Does
The program asks the user for basic information
(name, age, city, favorite subject) and displays
a student introduction.

## How to Run
1. Open the file in Python.
2. Run it.
3. Enter your name, age, city, and favorite subject.
4. See your introduction.

How old are you? 19
