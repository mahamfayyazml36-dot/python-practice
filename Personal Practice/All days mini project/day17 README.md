## What It Does

The program is a Delivery Cost & Logistics Utility System that performs different delivery, shipping, order, and discount calculations based on the user's selected option.

It can:

1. Display a menu of available operations

2. Calculate delivery cost based on parcel weight and delivery rate per kilogram

3. Calculate shipping charges based on parcel weight and shipping rate

4. Calculate the total order amount using quantity and product price

5. Calculate the discount amount and final price after discount

6. Check whether an order qualifies for free delivery

7. Display delivery charges of 250 when the order amount is below 5000

8. Repeat the menu until the user chooses to exit

9. Display an invalid choice message when the user selects an unsupported option

10. Exit the program using the Exit option

## How to Run

1. Open the Python file in VS Code or Python.

2. Run the program.

3. Select an operation from the displayed menu (1-6).

4. Enter the requested information, such as parcel weight, delivery rate, order quantity, product price, discount, or order amount.

5. The program will call the appropriate function.

6. The program will display the calculated result.

7. Select another operation to continue using the system.

8. Select option 6 to exit the program.
