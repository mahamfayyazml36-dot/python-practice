# Mini Project 13 - Ghazwa-e-Uhud Data Manager

This is my thirteenth Python mini project (Day 13 - Dictionaries Revision + Sets).

## Concepts Practiced
1. Dictionaries
2. Dictionary access using get()
3. Updating data using update()
4. Deleting data using pop()
5. items() method
6. Sets
7. Looping through sets
8. while loop
9. if / elif / else

## What It Does

The program is a menu-based battle data manager.
You can:

1. View Battle Data
2. Search Battle Data
3. Update Battle Data
4. Delete Battle Data
5. View Topics
6. Exit

## How to Run

1. Open the file in Python.
2. Run it.
3. Choose an option (1-6).
4. Follow the prompts.

## Difference from Day 12

- Day 12 used **nested dictionaries** (student → age, course, city)
- Day 13 uses a **flat dictionary** (key → value)
- Day 13 also introduces **sets** (uhud_topics) for storing unique topic names
- Day 13 uses `get()`, `update()`, and `pop()` more directly
