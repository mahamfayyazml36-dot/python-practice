# Mini Project 24 - DNA Base Counter & Sequence Analyzer

This is my twenty-fourth Python mini project (Day 24 - Nested Functions & Function Workflow + Previous Concepts).

## Concepts Practiced

1. Nested Functions
2. Inner & Outer Functions
3. Return Values
4. Function-to-Function Data Flow
5. Function Workflow
6. String Methods
7. DNA Base Counting
8. `len()` and `count()` Functions

## What It Does

The program gets a DNA sequence, cleans it using string methods, calculates its length using a nested function, counts each DNA base (A, T, G, C), and displays the final sequence analysis.
