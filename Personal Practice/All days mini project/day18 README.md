# Mini Project 18 - Community Event Planning & Readiness Report

This is my eighteenth Python mini project (Day 18 - Return in Python Functions + Previous Concepts).

## Concepts Practiced

1. Functions
2. Parameters and arguments
3. Return statement
4. Storing returned values
5. Using returned values again
6. Conditional statements
7. Returning multiple values
8. Combining functions with previous concepts

## What It Does

The program creates a community event planning and readiness report.  
It checks:

- Expected guests
- Venue capacity
- Total budget
- Estimated expenses
- Budget and venue status
- Final event readiness

## Example Output

```text
Final Community Event Planning & Readiness Report

Venue Capacity Check: Venue Ready
Total Budget: 600000
Estimated Expenses: 580000
Budget Status: Budget Sufficient
Budget and Venue Status: Venue Ready Budget Sufficient
Final Readiness: Event Ready
```
