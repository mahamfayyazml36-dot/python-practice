# Student Grade & Eligibility Analyzer

## 📌 Project Overview

**Student Grade & Eligibility Analyzer** is a beginner-level real-world Python mini project created as part of **Day 7 – Conditions + Loops Integration**.

This project processes multiple students based on their:

* Name
* Age
* Marks
* Attendance

The program calculates each student's grade, checks eligibility, counts eligible and not eligible students, and displays a final summary.

---

---

## ✅ Eligibility Criteria

A student is considered **Eligible** when all of the following conditions are satisfied:

* Age is **18 or above**
* Marks are **50 or above**
* Attendance is **75% or above**

All three conditions must be true.
