# 🎓 Day 10 — Student Record System

## 📌 Project Overview

This is a beginner-friendly **Student Record System** built with Python.

The project uses **Tuples** to store student records and provides a simple menu-driven system to view, search, and count students.

This mini project was created as part of my **Day 10 Python Learning Practice**.

## 🎯 Learning Objectives

Through this project, I practiced:

* Creating and using Tuples
* Accessing Tuple elements using indexing
* Using `len()` to count records
* Using `for` loops
* Using `while True`
* Using `if`, `elif`, and `else`
* Using Boolean values (`True` and `False`)
* Searching student records
* Using `.lower()` for case-insensitive searching
* Using `break` to exit a loop
* Taking input from the user
* Building a menu-driven Python program

## 🧑‍🎓 Student Records

The program contains student information in the following format:

```python
("Name", Age, "Field")
```

Example:

```python
("Leon", 18, "C++")
("Nilofer", 17, "Python")
("Jalan", 19, "AI")
("Gohar", 20, "Data analyst")
```

## 📋 Program Features

The program provides four menu options:

1. **View Student**
   Displays all student records.

2. **Search Student**
   Searches for a student by name.

3. **Count Student**
   Displays the total number of students.

4. **Exit**
   Exits the Student Record System.

## 🔎 Search Feature

The search system uses `.lower()` so that names can be searched without worrying about uppercase or lowercase letters.

For example:

```text
Maham
maham
MAHAM
```

can be treated as the same search input.
