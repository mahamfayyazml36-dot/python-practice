# Mini Project 28 - Custom Multiplication Table Generator

This is my twenty-eighth Python mini project (Day 28 - Iterators & Custom Iteration + Previous Concepts).

**## Concepts Practiced**

1\. Classes and Objects
2\. `__init__()` Method
3\. Multiple Parameters
4\. Object Attributes with `self`
5\. `__iter__()` Method
6\. `__next__()` Method
7\. Custom Iteration
8\. `StopIteration`
9\. `for` Loop with Custom Iterator
10\. f-Strings

**## What It Does**

The program creates a custom multiplication table generator using a Python class and custom iterator.

It takes a number, starting value, and ending value as parameters. The custom iterator generates the multiplication table one line at a time using `__iter__()` and `__next__()`.

The `for` loop automatically continues the iteration and stops when `StopIteration` is raised.
