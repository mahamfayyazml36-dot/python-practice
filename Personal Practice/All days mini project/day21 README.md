# Mini Project 21 - Chemical Solution Concentration Analyzer

This is my twenty-first Python mini project (Day 21 - Lambda Functions + Previous Concepts).

## Concepts Practiced

1. Lambda Functions
2. Parameters and arguments
3. Expressions
4. Automatic return
5. Conditional Lambda
6. Variables
7. Calculations
8. Function calls

## What It Does

The program calculates the concentration of a Sodium Chloride Solution using a Lambda Function and then checks whether the concentration is high or low using a conditional Lambda Function.

## Example Output

```text
10.0
High Concentration
Low concentration
```
