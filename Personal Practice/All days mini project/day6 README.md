## What It Does
The program takes student names and attendance (YES/NO).
It counts:
- Total students
- Present students
- Absent students

It shows a summary at the end.

## How to Run
1. Open the file in Python.
2. Run it.
3. Enter student name.
4. Enter YES or NO for attendance.
5. Type "exit" to stop and see the summary.
