# Mini Project 25 - Employee Salary Function Manager

This is my twenty-fifth Python mini project (Day 25 - Higher-Order Functions & Function Manager + Previous Concepts).

## Concepts Practiced

1. Higher-Order Functions
2. Functions as Return Values
3. Nested Functions
4. Closures
5. Function Manager using Dictionary
6. Dynamic Function Execution
7. Function Parameters & Return Values
8. `while True`, `break`, and `continue`
9. Input Validation
10. Function Workflow

## What It Does

The program creates different salary operations using nested functions and closures. It stores these functions in a function manager dictionary and dynamically executes the selected operation.

The user can choose to add a bonus, subtract tax, calculate a performance bonus, or exit the Salary Manager.
