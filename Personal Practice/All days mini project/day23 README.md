# Mini Project 23 - Scientific Calculation & Sequence Analyzer

This is my twenty-third Python mini project (Day 23 - Recursion + Previous Concepts).

## Concepts Practiced

1. Recursive Functions
2. Base Case
3. Factorial Calculation
4. Fibonacci Sequence
5. Recursion vs Loops

## What It Does

The program calculates the factorial of a number, generates a Fibonacci sequence, and analyzes even and odd numbers using recursion.
