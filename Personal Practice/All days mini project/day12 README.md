# Mini Project 12 - Student Database

This is my twelfth Python mini project (Day 12 - Dictionaries).

## Concepts Practiced
1. Dictionaries
2. Nested dictionaries
3. Dictionary access
4. Adding data
5. Searching data
6. Updating data
7. Deleting data
8. items()
9. pop()
10. in operator
11. while loop
12. if / elif / else

## What It Does

The program is a menu-based student database.
You can:

1. View all students
2. Search for a student
3. Add a new student
4. Update student information
5. Delete a student
6. Exit

## How to Run

1. Open the file in Python.
2. Run it.
3. Choose an option (1-6).
4. Follow the prompts.
