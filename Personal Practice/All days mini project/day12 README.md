# Mini Project 12 - Student Database

This is my twelfth Python mini project (Day 12 - Dictionaries).

## Concepts Practiced
- Dictionaries
- Nested dictionaries
- Dictionary access
- Adding data
- Searching data
- Updating data
- Deleting data
- items()
- pop()
- in operator
- while loop
- if / elif / else

## What It Does
The program is a menu-based student database.
You can:
1. View all students
2. Search for a student
3. Add a new student
4. Update student information
5. Delete a student
6. Exit

## How to Run
1. Open the file in Python.
2. Run it.
3. Choose an option (1-6).
4. Follow the prompts.
