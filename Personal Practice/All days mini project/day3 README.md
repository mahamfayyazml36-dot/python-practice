# Mini Project 3 - Simple Calculator

This is my third Python mini project.

## Concepts Practiced

1. input()
2. float()
3. Arithmetic operators (+, -, *, /, %, //, **)
4. if-else
5. Division by zero handling

## What It Does

The program takes two numbers from the user and performs:
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Modulus
6. Floor division
7. Power

It also checks if the second number is zero before dividing.

## How to Run

1. Open the file in Python.
2. Run it.
3. Enter two numbers.
4. See the results.
