## What It Does

The program is a menu-based inventory manager.
You can:

1. View inventory
2. Add product
3. Insert product
4. Remove product
5. Remove product by index
6. Update product
7. Check product
8. Count products
9. Sort inventory
10. Reverse inventory
11. Clear inventory
12. Exit

## How to Run

1. Open the file in Python.
2. Run it.
3. Choose an option (1-12).
4. Follow the prompts.
