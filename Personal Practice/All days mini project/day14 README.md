# Mini Project 14 - Army Cyber Defense Text Analyzer

This is my fourteenth Python mini project (Day 14 - Strings + Previous Concepts).

## Concepts Practiced

1. Strings

2. String indexing

3. Negative indexing

4. String slicing

5. String methods:
   - lower()
   - upper()
   - capitalize()
   - title()
   - strip()
   - replace()
   - find()
   - count()

6. Checking strings using:
   - startswith()
   - endswith()
   - in
   - not in

7. Splitting text using split()

8. Counting words using len()

9. f-string formatting

10. Escape characters (\n, \t, \")

11. if / else conditions

12. Combining previous Python concepts with strings


## What It Does

The program is an Army Cyber Defense mission text analyzer.

It can:

1. Display Soldier Profile

2. Analyze Mission Text

3. Count total characters and words

4. Find first and last characters

5. Extract first and last words

6. Search important words in the mission

7. Count word occurrences

8. Check mission status

9. Generate a final mission report


## How to Run

1. Open the file in Python.

2. Run it.

3. The program will display soldier information and analyze the mission text.

4. Follow the displayed report.
