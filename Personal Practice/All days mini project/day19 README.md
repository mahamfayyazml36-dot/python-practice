# Mini Project 19 - Emergency Response & Rescue Operations Tracker

This is my nineteenth Python mini project (Day 19 - Scope: Local and Global Variables + Previous Concepts).

## Concepts Practiced

1. Local variables
2. Global variables
3. Local vs global scope
4. Same variable name in different scopes
5. `global` keyword
6. Functions
7. Parameters and arguments
8. Return statement
9. Conditional statements
10. Returning multiple values
11. Combining functions with previous concepts

## What It Does

The program creates an emergency response and rescue operations report.  
It handles:

- Emergency report
- Emergency priority
- Rescue unit assignment
- Available rescue units
- Operation status
- Local and global variable scope
- Final emergency operation summary
