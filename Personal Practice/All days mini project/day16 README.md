## What It Does

The program is a Mini Calculator that performs a mathematical operation based on the user's selected operation.

It can:

1. Take the first number from the user

2. Take the second number from the user

3. Take the desired operation from the user

4. Perform addition

5. Perform subtraction

6. Perform multiplication

7. Perform division

8. Calculate modulus (remainder)

9. Calculate power

10. Perform floor division

11. Handle division by zero

12. Handle modulus by zero

13. Handle floor division by zero

14. Display the result of the selected operation

15. Display an invalid operation message if the user enters an unsupported operation

## How to Run

1. Open the Python file in VS Code or Python.

2. Run the program.

3. Enter the first number.

4. Enter the second number.

5. Enter one of the supported operations:

   * +
   * -
   * *
   * /
   * %
   * **
   * //

6. The program will call the appropriate function.

7. The program will display the result of the selected operation.
