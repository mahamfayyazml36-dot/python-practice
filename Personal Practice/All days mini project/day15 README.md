# Mini Project 15 - Job Application Profile & Resume Analyzer

This is my fifteenth Python mini project (Day 15 - String Methods & Formatting + Previous Concepts).

## Concepts Practiced

1. String methods

2. Removing extra spaces using:

   * strip()

3. Formatting text using:

   * title()

4. Checking strings using:

   * in
   * endswith()

5. Checking numbers using:

   * isdigit()

6. Counting characters using len()

7. Removing duplicate skills using set()

8. Joining skills using join()

9. f-string formatting

10. Decimal formatting using `:.2f`

11. Escape characters:

* \n
* \t

12. if / else conditions

13. Using `and` with validation

14. Combining previous Python concepts with string methods

## What It Does

The program is a Job Application Profile & Resume Analyzer.

It can:

1. Display Job Applicant Profile

2. Clean and format the applicant's name

3. Validate email information

4. Validate phone number

5. Clean and format city name

6. Format career field

7. Remove duplicate skills

8. Display skills in a readable format

9. Calculate project points

10. Format test score

11. Calculate assessment percentage

12. Display email and phone validation status

13. Generate a final job application profile

## How to Run

1. Open the file in Python.

2. Run it.

3. The program will process the job application information.

4. The program will display the formatted profile and validation results.
